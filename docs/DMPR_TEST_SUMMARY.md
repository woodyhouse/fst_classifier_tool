## 问题分析

### 为什么 DMPR-PS 在你的数据上效果差？

1. **训练数据不匹配**
   - DMPR-PS 训练数据：标准停车场鸟瞰图（环视相机）
   - 你的数据：地面视角，透视畸变严重
   - 即使做了 BEV 变换，质量仍不如真实鸟瞰图

2. **检测目标不同**
   - DMPR-PS 检测：车位标记点（marking points）
   - 你的需求：完整车位线 + 9宫格映射
   - 标记点 ≠ 车位线

3. **场景差异**
   - DMPR-PS：室外标准停车场
   - 你的数据：可能包含室内、地下、特殊场景

## 结论与建议

### ❌ 不推荐使用 DMPR-PS

**原因：**
1. 成功率太低（18-25%）
2. 即使检测到点，也无法形成完整车位（大多数只有1个点）
3. 需要大量调参和数据适配工作
4. 不适合地面视角的数据

### ✅ 推荐方案

#### 方案 A：简化你的项目（最推荐）

**删除复杂模块，保留核心功能：**

```
保留：
✓ YOLO 物体检测（检测车辆、路沿、障碍物）
✓ CNN 场景分类（车位类型、标线颜色等）
✓ 简单的霍夫直线检测（检测车位线）

删除：
✗ 消失点检测（vanishing_point.py）
✗ 透视校正（parking_geometry.py 部分）
✗ 深度学习车位线检测（dl_marking_point_detector.py）
✗ DMPR-PS 集成
```

**新的简化流程：**
```
输入图片
  ↓
YOLO 检测障碍物 → 障碍物列表
  ↓
CNN 分类 → 车位类型、标线特征
  ↓
霍夫直线检测 → 车位线位置（粗略）
  ↓
规则映射 → 9宫格
  ↓
FST JSON 输出
```

**优点：**
- 代码量减少 60%
- 不依赖复杂的几何算法
- 对数据要求低（500-1000 张即可）
- 可解释性强

**缺点：**
- 车位线定位不够精确
- 但对于 FST 分类任务已经够用

#### 方案 B：使用传统 CV 方法

**不用深度学习，纯传统计算机视觉：**

```python
def detect_parking_slot_simple(image):
    # 1. 边缘检测
    edges = cv2.Canny(gray, 50, 150)

    # 2. 霍夫直线检测
    lines = cv2.HoughLinesP(edges, ...)

    # 3. 分类垂直/水平线
    v_lines = filter_vertical(lines)
    h_lines = filter_horizontal(lines)

    # 4. 拟合矩形
    slot = fit_rectangle(v_lines, h_lines)

    return slot
```

**优点：**
- 无需训练数据
- 速度快（~50ms CPU）
- 对清晰车位线效果不错

**缺点：**
- 对模糊、遮挡敏感
- 需要手工调参
