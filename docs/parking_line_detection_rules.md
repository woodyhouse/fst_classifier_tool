# 车位线检测算法优化规则

## 算法概述
基于边缘检测和霍夫直线变换的车位线识别算法，通过多重规则过滤提高检测准确性。

## 预处理阶段

### 1. 图像增强
- **CLAHE对比度增强**: 自适应直方图均衡化，增强局部对比度
- **高斯模糊**: 7x7核，减少噪声干扰
- **Canny边缘检测**: 降低阈值(30, 100)以检测更多边缘

### 2. 线段检测与合并
- **霍夫直线变换**: 降低阈值到40，增加maxLineGap到3倍
- **共线线段合并**:
  - 角度差小于10度
  - 点到直线距离小于20像素
  - 使用SVD找到最佳拟合直线
  - 合并断裂的长边线段

## 核心过滤规则

### 规则1: 天花板区域过滤
**目的**: 排除天花板上的灯具、管道等干扰
- 判断线段中点是否在图片上方1/3区域
- 如果两条线都在天花板区域，则跳过

### 规则2: 角度合理性检查
**目的**: 排除墙壁、柱子等非车位线
- 车位线角度应在15°-75°之间
- 排除接近水平的线(0-15°): 可能是墙壁或天花板边缘
- 排除接近垂直的线(75-90°): 可能是柱子或墙角

### 规则3: 最小长度要求
**目的**: 过滤短线段噪声
- 线段长度应大于图片尺寸的8%
- 确保检测到的是完整的车位线

### 规则4: 长度相似性检查
**目的**: 车位线两边应该长度接近
- 两条线长度比例不超过3:1
- 排除一长一短的不匹配线对

### 规则5: 平行性判定
**目的**: 车位线必须平行
- 角度差小于5度（可调参数）
- 考虑180度周期性，归一化到0-180度

### 规则6: 投影重叠比例
**目的**: 防止错位的平行线被误判
- 计算两条线在垂直方向的投影重叠
- 重叠比例应大于30%
- 确保两条线真正对应同一个车位

### 规则7: 距离合理性
**目的**: 车位宽度应在合理范围
- 最小距离: 30像素（可调）
- 最大距离: 150像素（可调）
- 排除过窄或过宽的线对

### 规则8: 颜色一致性
**目的**: 车位内部应该是地面颜色
- **白色判定**: 饱和度<80, 亮度>100
- **黄橙色判定**: 色调15-50, 饱和度>30, 亮度>80
- **灰色地面**: 饱和度<50, 亮度>50
- 在HSV色彩空间进行判定

## 参数说明

### 可调参数
```python
min_line_length = 50          # 最小线段长度
max_line_gap = 10             # 线段间最大间隙
parallel_angle_threshold = 5.0 # 平行角度阈值
min_distance = 30             # 最小车位宽度
max_distance = 150            # 最大车位宽度
min_overlap_ratio = 0.3       # 最小重叠比例
max_length_ratio = 3.0        # 最大长度比例
```

## 优化建议

### 针对不同场景的调整

**室内停车场（光线较暗）**
- 增加CLAHE的clipLimit到3.0
- 降低Canny阈值到(20, 80)
- 放宽颜色判定条件

**室外停车场（光线充足）**
- 保持默认参数
- 可以提高颜色判定的亮度要求

**透视角度较大**
- 增加max_line_gap到更大值
- 降低min_overlap_ratio到0.2
- 放宽max_length_ratio到4.0

**高分辨率图像**
- 按比例增加min_line_length
- 按比例增加min_distance和max_distance

## 已知限制

1. **透视变形**: 严重透视会导致线段弯曲，难以检测
2. **遮挡问题**: 车辆遮挡车位线时无法检测
3. **磨损线条**: 严重磨损的车位线可能检测不到
4. **复杂背景**: 地面纹理复杂时可能产生误检

## 未来改进方向

1. **深度学习方法**: 使用CNN进行端到端检测
2. **透视校正**: 先进行透视变换再检测
3. **时序信息**: 利用视频帧间信息提高稳定性
4. **语义分割**: 先分割出地面区域再检测线条
5. **多尺度检测**: 在不同尺度上进行检测并融合结果
