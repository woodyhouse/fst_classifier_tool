# 地面视角车位线检测 - 模板匹配使用指南

## 更新说明

已针对地面视角拍摄场景优化模板库：

### 地面视角特点
- **强透视变形**：远端宽度可能只有近端的10-20%
- **角度变化大**：手机拍摄角度不固定
- **尺寸范围广**：距离不同导致车位在图像中大小差异大

### 新模板库参数
- **模板总数**：7200个
- **透视系数**：0.1-0.8（覆盖强透视场景）
- **车位宽度**：60-150像素
- **车位长度**：150-300像素
- **旋转角度**：0-165度（每15度一个）
- **线宽**：8/12/16像素

### 性能优化
- **分层匹配**：先用100个代表性模板粗匹配，再在附近精细搜索
- **匹配速度**：相比全量搜索提速约70倍

## 使用方法

### 方法1：使用可视化工具（推荐）

```bash
python parking_line_viewer.py
```

操作步骤：
1. 点击"打开图片"加载车位照片
2. 勾选"使用模板匹配"（首次会自动加载模板库）
3. 点击"重新检测"
4. 查看检测结果

### 方法2：代码调用

```python
from fst.template_parking_detector import TemplateParkingDetector
import cv2

# 初始化检测器
detector = TemplateParkingDetector(
    template_path="parking_templates_ground.pkl"
)

# 读取图片
image = cv2.imread("parking.jpg")

# 准备线段（可以从其他检测器获取）
lines = [...]  # 格式: [[x1, y1, x2, y2], ...]

# 检测车位
matches = detector.detect(
    image,
    lines,
    score_threshold=0.35  # 分数阈值，可调整
)

# 可视化结果
detector.visualize(image, matches, "result.jpg")

# 查看结果
for i, match in enumerate(matches):
    print(f"车位{i+1}: 分数={match.score:.3f}")
```

## 参数调整建议

### score_threshold（分数阈值）
- **0.3-0.4**：宽松，检测更多候选（可能有误检）
- **0.4-0.5**：平衡（推荐）
- **0.5-0.7**：严格，只保留高置信度结果

### 线段检测参数（在viewer中调整）
- **最小线段长度**：50-100像素（地面视角车位线较长）
- **平行角度阈值**：5-10度
- **距离范围**：15-150像素（车位宽度）

## 常见问题

**Q: 为什么检测不到车位？**
A: 可能原因：
- 线段检测参数不合适，调整"最小线段长度"和"距离范围"
- 分数阈值过高，尝试降低到0.3
- 车位线不清晰或被遮挡

**Q: 检测到很多误检怎么办？**
A: 提高score_threshold到0.5以上，或调整线段检测参数

**Q: 模板库加载很慢？**
A: 7200个模板首次加载需要几秒，后续使用分层匹配会很快

**Q: 可以自定义模板参数吗？**
A: 可以，修改generate_ground_templates.py中的参数范围，重新生成模板库
