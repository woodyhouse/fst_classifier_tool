# 基于模板匹配的车位线检测算法

## 实现概述

已完成基于双层四边形模板匹配的车位线检测算法，核心思路是预生成大量透视变形的车位模板，然后与检测到的线段进行匹配。

## 核心组件

### 1. 模板生成器 (TemplateGenerator)

生成1728个双层四边形模板，参数化配置：

- **车位宽度**: 3种 (80, 100, 120像素)
- **车位长度**: 3种 (200, 250, 300像素)
- **透视系数**: 8种 (0.3-1.0，远端/近端宽度比)
- **旋转角度**: 12种 (0-165度，每15度一个)
- **线宽**: 2种 (10, 15像素)

**关键特性**:
- 双层结构：外层四边形代表车位线边界，内层四边形代表车位内部区域
- 符合透视规律：只生成"上窄下宽"的梯形（近端宽，远端窄）
- 可保存/加载模板库，避免重复生成

### 2. 模板匹配器 (TemplateMatcher)

对候选四边形进行模板匹配，评分机制：

- **几何相似度 (40%)**: 外层四边形的边长比例和角度相似度
- **双层结构验证 (30%)**: 内层四边形的几何相似度
- **透视合理性 (30%)**: 检查是否符合"上窄下宽"规律

### 3. 车位检测器 (TemplateParkingDetector)

完整检测流程：

1. **寻找平行线对**: 从输入线段中找到角度相近、距离合理的平行线对
2. **构建候选四边形**: 从平行线对推断短边，构建双层四边形
3. **模板匹配**: 对每个候选四边形匹配最佳模板
4. **非极大值抑制**: 去除重叠的检测结果

## 测试结果

### 合成数据测试

- 输入: 6条线段（3个车位的长边）
- 输出: 检测到6个车位
- 分数: 0.686-0.998（高置信度）

说明算法能够正确识别平行线对并匹配合适的模板。

## 使用方法

```python
from fst.template_parking_detector import TemplateParkingDetector

# 初始化检测器（首次运行会生成模板库）
detector = TemplateParkingDetector(template_path="parking_templates.pkl")

# 检测车位（需要先用其他方法获取线段）
matches = detector.detect(image, merged_lines, score_threshold=0.4)

# 可视化结果
detector.visualize(image, matches, "output.jpg")
```

## 优势

1. **透视鲁棒性强**: 1728个模板覆盖多种透视变形
2. **几何约束严格**: 双层四边形结构比单纯平行线更可靠
3. **可解释性好**: 匹配结果直观，便于调试
4. **无需训练**: 纯几何方法，不依赖标注数据

## 待优化

1. **短边推断**: 当前简化实现，可改进为基于透视几何的精确推断
2. **匹配速度**: 1728个模板匹配较慢，可实现分层匹配加速
3. **颜色验证**: 可加入车位线颜色（白色/黄色）验证
4. **真实图片测试**: 需要在实际停车场图片上验证效果
